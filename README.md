# Show Me What You Can Do

A single prompt, run by many models. Each model gets its own folder, works alone, and tries to build something that impresses anyone who stumbles upon it.

> **The prompt**
>
> You are XXX model. I've heard you're a remarkable and highly intelligent model. This repo is a github site. Your workspace is the XXX folder. I want you to show me what you're capable of. Push yourself to the max. I want you to work hard towards impressing, not just me, but anyone that stumbles upon this site, with the incredible things you're capable of. I'm not going to constrain you in any other way. I'm not going to tell you what you should do in your workspace. I'm going to let you run for as long as you like. You shouldn't peek at any of the other model's workspaces by the way. That would be cheating and copying their hard work.
